# GloboUp File — versioni di prova

Installer di prova di GloboUp File per Windows x64 e Mac Apple silicon. Download e istruzioni: https://www.globoup.com/computer/

Questo repository contiene esclusivamente file di distribuzione pubblici. Non contiene codice privato, credenziali, documenti o dati degli utenti.

Windows: installer non firmato, collaudo su PC reale ancora da completare. Mac: firma Apple Development, senza notarizzazione; avvio su altri Mac non verificato. Non supporta Mac Intel.
